04

同一个 MLP，两种常见写法

能力并无硬边界。这里比较的是初学与日常项目中最典型的两种风格：显式训练循环 vs 框架标准流程。

PyTorch · 显式训练循环

每一步都摆在眼前，便于理解与逐步调试

容易观察每一步
1optimizer.zero_grad() # 清空旧梯度
2hidden = torch.sigmoid(x @ W + b)
logits = hidden @ v + c
3loss = F.binary_cross_entropy_with_logits(logits, y)
4loss.backward() # 梯度写入 .grad
5optimizer.step() # 更新参数

TensorFlow / Keras · 标准流程

把常规训练交给框架，快速得到模型

快速搭建
1model = keras.Sequential([
  layers.Dense(2, activation="sigmoid"),
  layers.Dense(1)
])
2model.compile(optimizer="adam", loss="bce")
3model.fit(x, y, epochs=300)
PyTorch 常见风格更显式 · 更便于逐步观察
TensorFlow / Keras 常见风格更封装 · 更快搭建标准模型

一轮训练里发生了什么

1

前向计算

当前参数把四个输入映射成四个预测概率。

2

计算损失

二元交叉熵衡量预测与目标之间的距离。

3

反向传播

链式法则求出每个权重对损失的梯度。

4

Adam 更新

结合梯度的一阶、二阶动量调整所有参数。
